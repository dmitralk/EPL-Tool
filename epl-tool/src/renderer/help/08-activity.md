# Activity log

Every change is recorded in the **activity log**, in the same step as the change itself: who, when, and what changed.
Everybody can read it.

## Where to see it

- **Settings → Activity** — the whole log. Filter by user, area or exact action, customer, date and text; click a line to
  see the details (fields old → new, counts). **Export to Excel** exports what the filters show.
- **History** on each customer page — that customer's entries.
- The price list page shows **who created** the list.

## What is recorded

- customers: create, update, hide, restore, permanent delete, pricing management changes
- price lists: create, delete
- email addresses: assign, replace, remove
- products, Standard EPL (drafts, prices, publish, discard), packaging, currencies, units
- PBP emails, the logo, default FX rates, users, backup restores

Each entry shows the person's name and Windows account. When an admin uses **Preview as…**, entries read
*"Admin (account) as Previewed user"*.

The log started with v0.6: older changes are not in it.
